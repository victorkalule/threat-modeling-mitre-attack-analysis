# Project 4 — Threat Modeling & MITRE ATT&CK Analysis

**Recommended repository name:** `threat-modeling-mitre-attack-analysis`

These Markdown files form a recruiter-facing cybersecurity portfolio project based on the Xibalba Interactive training threat model and accompanying worksheet in Google Drive.

## Files

- `README.md` — main project overview
- `docs/risk-assessment-highlights.md` — worksheet-based risk prioritization and representative attack scenarios
- `docs/defensive-roadmap.md` — monitoring, deception, and preventive controls recommended in the training report
- `PUBLICATION_CHECKLIST.md` — review steps required before public release

## Important distinctions

- Risk scores and attack paths come from a **hypothetical training scenario**.
- MITRE ATT&CK identifiers represent **modeled** techniques, not observed attacks.
- Proposed controls (honeypots, monitoring rules, segmentation) are **recommendations**, not completed implementations.
- Original source reports/templates are not included.
