# Public Release Checklist

Before switching this repository from **private** to **public**:

- [ ] Confirm TripleTen training terms allow original public write-ups based on the scenario.
- [ ] Verify asset and threat scenario summaries match the original report and worksheet.
- [ ] Keep source course templates, unfinished sections, and restricted materials out of the repository.
- [ ] Remove credentials, personal data, private endpoints, internal network details, and any sensitive screenshots.
- [ ] Do not present threat scenarios as confirmed compromises or proposed security controls as deployed systems.
- [ ] Label risk scores as **scenario-based estimates** on the worksheet's additive scale, not factual probabilities.
- [ ] Add images, charts, or screenshots only if independently created or explicitly permitted for public distribution.
- [ ] Review spelling, links, and displayed technical terms before publication.
